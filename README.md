여러 사이트의 공모전을 한 표에서 찾고 접수기간과 상금을 비교하는 Windows 로컬 앱입니다.

## 실행

Python 3.10 이상과 Microsoft Edge가 설치된 Windows에서 `start.cmd`를 실행한 뒤 브라우저에서 `http://127.0.0.1:8768/`을 엽니다. 첫 실행에 필요한 Python 패키지를 설치합니다. 빈 데이터 폴더에서 시작하면 자동으로 첫 수집을 실행합니다.

1. **수집 새로고침**으로 대티즌, 콘테스트코리아, 위비티, 요즘것들(올포영), 씽굿의 공개 목록을 확인합니다. 접수 중인 웹·앱·소프트웨어 개발, 코딩·해커톤, AI·데이터 분석, 게임 개발 공모전을 수집합니다. 제목과 분야가 후보에 해당하면 상세 요강을 확인하고 대표 이미지를 가져옵니다.
2. 공모전명, 주최 기관, 키워드를 검색합니다. 열 머리글을 누르면 그 열을 정렬하거나 필터링할 수 있습니다. 여러 열의 필터를 함께 적용할 수 있습니다.
3. 대표 이미지나 사이트출처 링크를 누르면 수집한 개별 공고가 새 탭에서 열립니다. 홈페이지 링크는 주최 측 페이지를, 온오프믹스 링크는 공모전 목록을 엽니다.

왼쪽 **수집 페이지** 메뉴는 화면이 좁아지면 상단에 표시됩니다. **전체 열**을 누르면 분야, 응모대상, 주최/주관, 후원/협찬, 1등 상금, 홈페이지도 정렬하고 필터링할 수 있습니다.

마감일은 한국 날짜 기준으로 계산하며, 접수기간 항목에 시간이 있으면 그 시간도 적용합니다. 공고에 금액 범위가 있으면 원래 표기를 표시하고 금액 정렬에는 읽을 수 있는 범위 하한을 사용합니다. 확인되지 않은 필드는 `—`로 표시합니다. 같은 공모전은 한 행으로 표시하며 사이트출처에서 수집한 원문을 모두 열 수 있습니다. 사이트출처로 필터링해도 표시된 행의 원문 링크는 모두 유지됩니다.

## 수집 및 저장

Scrapling으로 공고의 공개 HTML을 읽고, 목록이 브라우저에서 만들어지는 사이트에는 Playwright와 Edge를 사용합니다. 사이트별 수집 스냅샷과 포스터는 `data` 폴더에 저장합니다. 목록이나 상세 조회가 중단되면 해당 사이트 상태를 표시하고, 이전에 수집한 공고 중 접수 중인 항목을 함께 보여줍니다.

다른 수집 페이지를 추가할 때는 본문 HTML을 `public`에 두고, `app.py`의 `PAGES`에 경로, 메뉴명, 본문 파일과 필요한 스크립트·스타일을 등록합니다. 새 정적 파일은 `STATIC`에 등록합니다. 등록한 페이지는 공통 메뉴에 표시되며 현재 페이지가 자동으로 강조됩니다.

## 검증

앱을 실행한 상태에서 PowerShell의 프로젝트 폴더에서 아래 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
.\.venv\Scripts\python.exe -X utf8 tests/live_check.py
```

두 번째 명령은 실제 사이트를 새로 조회합니다. 저장된 공고와 포스터로 화면만 다시 검사하려면 `--use-cache`를 붙입니다.
